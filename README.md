# Darknes OS

Android home-screen launcher with a dark graphite and gold visual identity.

## Build APK
GitHub Actions builds a debug APK on every push to `main`.

1. Open the **Actions** tab.
2. Select **Android APK**.
3. Open the latest successful run.
4. Download the `Darknes-OS-debug` artifact.

## Features in this first build
- Can be selected as the Android Home app.
- Discovers installed launcher apps and opens them.
- Search/filter for installed apps.
- Responsive portrait and landscape layout.
- Dark graphite interface with gold accents.
- Quick links to Android Settings.

Minimum Android version: Android 8.0 (API 26).
